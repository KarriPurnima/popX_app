# popX_app

A frontend assignment recreating the PopX mobile UI flow — built with React, Vite, Tailwind CSS, and React Router.

## 📱 Screens

- **Welcome Screen** — Landing screen with "Create Account" and "Already Registered? Login" actions
- **Login Screen** — Email and password sign-in form
- **Signup Screen** — Full registration form (name, phone, email, password, company, agency toggle)
- **Account Settings** — User profile summary screen

## 🛠️ Tech Stack

- [React](https://react.dev/) — UI library
- [Vite](https://vitejs.dev/) — Build tool & dev server
- [Tailwind CSS](https://tailwindcss.com/) — Styling
- [React Router](https://reactrouter.com/) — Client-side routing
- [Lucide React](https://lucide.dev/) — Icons

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
git clone https://github.com/KarriPurnima/popX_app.git
cd popX_app
npm install
```

### Run locally

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build for production

```bash
npm run build
```
